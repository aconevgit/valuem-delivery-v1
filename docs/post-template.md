## First H2 — Name the Problem Clearly

### H3 — A Specific Sub-Point If Needed

Use H3 only when a section is long enough to need internal structure. If in doubt, use a new H2 instead.

## Second H2 — The Insight or Turning Point

Each section should move the reader forward — avoid restating the previous section.

**Bold** key terms when they first appear. No more than 2–3 per article — overuse dilutes emphasis.

> A single sentence that captures the most important insight. One blockquote per article.
